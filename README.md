# Mirror Automation

This repository contains GitHub Actions Workflows to mirror upstream repositories to the `pism` GitHub Organization. 

Typically, this is done to improve performance of CI workflows where the upstream repository can't handle the request volume generate by our workflows.

## Current mirrors

YAC - Yet Another Coupler:
* Upstream: https://gitlab.dkrz.de/dkrz-sw/yac
* Mirror: https://github.com/pism/yac-mirror

YAXT - Yet Another eXchange Tool:
* Upstream: https://gitlab.dkrz.de/dkrz-sw/yaxt
* Mirror: https://github.com/pism/yaxt-mirror
